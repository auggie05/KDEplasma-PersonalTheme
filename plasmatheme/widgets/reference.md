# tasks.svg

## Directions

No direction = Task bar at bottom
Cardinal direction = Task bar at that side

## Types of tasks

Tasks are what would be windows on your taskbar in Windows.

### Focus

The window you are currently tabbed-in on.

### Minimized

Shown when a window is running but not on screen.

### Normal

Shown when a window is running and on screen but not tabbed-in on.

### Attention

A window showing a warning.

### Hover

Shown when hovering over an icon.

### Progress

Shown when a window is progressing through something. Think copying large files in File Exporer.
